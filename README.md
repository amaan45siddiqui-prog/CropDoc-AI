# 🌱 CropDoc AI
### An Intelligent Plant Disease Detection and Classification System Using Deep Learning

CropDoc AI is an AI-powered web application designed to identify plant diseases from leaf images using Deep Learning and Computer Vision.

The application uses a Convolutional Neural Network (CNN) with MobileNetV2 to classify plant leaf images into different healthy and diseased categories. It provides prediction results, confidence scores, disease information, common symptoms, and general plant care recommendations.

## 🚀 Features

- **AI-Based Disease Detection:** Predicts plant health categories from uploaded leaf images.
- **38 Classification Classes:** Supports 38 categories of healthy and diseased leaves.
- **Confidence Score:** Displays the model's prediction confidence.
- **Disease Information:** Provides basic information about the predicted disease.
- **Symptoms and Care Tips:** Displays common symptoms and general preventive care suggestions.
- **PDF Report Generation:** Allows users to download a PDF report of prediction results.
- **Interactive Web Interface:** Simple and user-friendly interface developed using Streamlit.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**2. Open the project directory**

```bash
cd CropDoc_AI
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate the virtual environment (Windows)**

```bash
.venv\Scripts\activate
```

**5. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
streamlit run app.py
```

The application will open in your browser.

## 📊 Dataset

The project uses the PlantVillage dataset, a publicly available collection of plant leaf images used for plant disease classification research.

The dataset contains images representing healthy and diseased plant leaves across multiple crop categories.

Dataset source: https://www.kaggle.com/datasets/emmarex/plantdisease

## 🧠 Model Information

The application uses MobileNetV2, a lightweight convolutional neural network architecture, through transfer learning.

The trained model is used to classify uploaded leaf images into one of the supported categories.

## ⚠️ Disclaimer

CropDoc AI is an educational and experimental AI-based project. Its predictions are generated by a trained machine learning model and should not be considered a confirmed plant disease diagnosis. Prediction confidence does not guarantee correctness. Users should seek expert agricultural advice before making important crop-management decisions.
